# v2 — AI 코딩 에이전트 인프라 사이징 계산기

개발 인원 · 모델 체급 · 작업 범위(컨텍스트)에 따른 **필수 GPU 자원과 제약사항**을 한 화면에서 판별하는 대시보드입니다. (파일: [index.html](index.html), 단일 파일)

> 상태: 초기 버전 반입 완료 — **기능 검토 및 업데이트 진행 예정**

## 입력 (3대 핵심 조건)
| 입력 | 선택지 |
| :--- | :--- |
| 모델 | Qwen 14B FP16 · Qwen 32B INT4 · Qwen 32B FP16(표준) · 70B FP8 |
| 동시 활성 인원 | 1~30명 (전체 팀원의 30~50%가 동시 사용한다고 가정) |
| 작업 깊이(컨텍스트) | 16k · 32k(권장) · 64k · 128k |

## 계산 모델
```
필요 VRAM = 고정 메모리(모델 가중치 + 런타임 버퍼) + (1k 토큰당 KV Cache × 컨텍스트 k × 동시 인원)
최대 동시 인원 = floor((장비 VRAM − 고정 메모리) / 1인당 KV Cache)
예상 tps ≈ (대역폭 × 0.62) / (가중치 + 1인당 KV) × 동시 인원 보정계수
```
KV Cache는 FP8 기준이며, tps 기준선은 28~30 tps입니다.

## 출력
- 현재 조건 진단 배너 (필요 메모리, 권장 장비, 160GB 기준 최대 인원)
- 인원 증가에 따른 필요 VRAM 곡선과 80/160/320GB 한계선 차트
- 장비별 판정 표: H100×1, GB10(DGX Spark), A100×2, H100×2, H200×2, H100×4 — 최대 인원 · 예상 tps · 제약사항(메모리 부족 / 대역폭 병목 / 안정)

## 실행
브라우저에서 `index.html`을 열면 됩니다. Tailwind CSS, Chart.js, Font Awesome, Pretendard를 CDN으로 불러오므로 인터넷 연결이 필요합니다.
